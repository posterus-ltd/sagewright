# Sage v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v1 core loop — from a browser, describe a task for a repo → a worker container spawns → an opencode agent works/validates/reflects (≤3) → pushes a branch and opens a PR → the user watches live and can interject, surviving dropped connections.

**Architecture:** nx monorepo. A Fastify control-plane API owns Postgres (Drizzle), the Docker socket (dockerode), and all secrets. Workers are per-task Docker containers running a harness-agnostic runner loop that drives opencode via a `Harness` adapter and streams a persisted, resumable event log back to the API over SSE. A React/MUI SPA renders sessions and live transcripts.

**Tech Stack:** TypeScript, nx, npm, Fastify, Drizzle + Postgres (`pg`), `dockerode`, `zod`, opencode (`opencode serve`), React 19, MUI, react-router v7 (library mode), `@tanstack/react-query`, `notistack`, vite, vitest, msw, Docker / docker-compose.

## Global Constraints

- Language: TypeScript everywhere. Package manager: **npm**. Bundler: **vite**.
- Frontend: React **19**, `@mui/material` + `@emotion/react` + `@emotion/styled`, `react-router` (library mode via `createBrowserRouter`), `@tanstack/react-query`, `notistack`, `zod`, `react-i18next`.
- Testing: **vitest** (unit + integration), co-located `*.test.ts(x)` next to source, `msw` for frontend network mocking, `playwright` reserved for later e2e.
- TypeScript style (`alignment/CONVENTIONS.md`): use `enum ExampleEnum { FIRST = 'first' }` instead of string-literal unions; **named exports** only (no default exports); `const` arrow functions; React components as `FC` arrow functions; custom hooks for business logic.
- Naming: files kebab-case for utilities, PascalCase for components; vars/functions camelCase; constants UPPER_SNAKE_CASE; types/interfaces PascalCase; booleans prefixed `is/has/should/can`.
- File size: >300 lines is a smell; functions <20 lines, ≤3 params; no deep nesting (>3); no magic strings/numbers.
- Group by feature/domain, not file type. Keep index files thin (re-exports only). No circular deps; apps depend on libs, never on each other; `harness` depends only on `shared`.
- Workflow: TDD (red → green → commit). Frequent commits. Branch `feat/sage-v1`.
- Trust model: single trusted team, one Docker host, shared-secret login, sessions tagged by user. Only the control plane mounts the Docker socket.
- Status enum verbatim: `queued → provisioning → running → needs_assistance → pushing → done | failed | cancelled`.

```ts
import { EventType } from '@sage/shared';

import type { HarnessEvent } from '../harness';

interface RawEvent {
  type?: string;
  properties?: { part?: { type?: string; text?: string; tool?: string; state?: { status?: string } } };
}

export const normalizeOpencodeEvent = (raw: unknown): HarnessEvent | null => {
  const event = raw as RawEvent;
  if (event.type !== 'message.part.updated') return null;
  const part = event.properties?.part;
  if (!part) return null;
  if (part.type === 'text' && typeof part.text === 'string') {
    return { type: EventType.ASSISTANT, payload: { text: part.text } };
  }
  if (part.type === 'tool' && part.tool) {
    return { type: EventType.TOOL, payload: { tool: part.tool, status: part.state?.status ?? 'unknown' } };
  }
  return null;
};
```

`libs/harness/src/opencode/opencode-client.ts`:
```ts
export class OpencodeClient {
  constructor(private readonly baseUrl: string) {}

  async createSession(title: string): Promise<{ id: string }> {
    const res = await fetch(`${this.baseUrl}/session`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ title }),
    });
    if (!res.ok) throw new Error(`createSession failed: ${res.status}`);
    return (await res.json()) as { id: string };
  }

  async sendPrompt(sessionId: string, text: string): Promise<void> {
    const res = await fetch(`${this.baseUrl}/session/${sessionId}/message`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ parts: [{ type: 'text', text }] }),
    });
    if (!res.ok) throw new Error(`sendPrompt failed: ${res.status}`);
  }

  async *subscribe(signal: AbortSignal): AsyncIterable<unknown> {
    const res = await fetch(`${this.baseUrl}/event`, { signal });
    if (!res.body) throw new Error('no event stream body');
    const reader = res.body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });
      const chunks = buffer.split('\n\n');
      buffer = chunks.pop() ?? '';
      for (const chunk of chunks) {
        const line = chunk.split('\n').find((l) => l.startsWith('data: '));
        if (line) yield JSON.parse(line.slice(6));
      }
    }
  }
}
```

`libs/harness/src/opencode/opencode-harness.ts`:
```ts
import { spawn as nodeSpawn } from 'node:child_process';

import type { Harness, HarnessEvent, HarnessSession, HarnessStartOpts } from '../harness';
import { OpencodeClient } from './opencode-client';
import { normalizeOpencodeEvent } from './normalize';

export interface SpawnedServer { baseUrl: string; stop: () => Promise<void> }
export type SpawnFn = (opts: HarnessStartOpts) => Promise<SpawnedServer>;

interface OpencodeHarnessDeps {
  spawn?: SpawnFn;
  clientFactory?: (baseUrl: string) => OpencodeClient;
}

const defaultSpawn: SpawnFn = (opts) =>
  new Promise((resolve, reject) => {
    const child = nodeSpawn('opencode', ['serve', '--port', '0', '--hostname', '127.0.0.1'], {
      cwd: opts.cwd,
      env: process.env,
    });
    child.stdout.on('data', (buf: Buffer) => {
      const match = /http:\/\/[\d.]+:\d+/.exec(buf.toString());
      if (match) resolve({ baseUrl: match[0], stop: async () => void child.kill() });
    });
    child.on('error', reject);
  });

export class OpencodeHarness implements Harness {
  private readonly spawn: SpawnFn;
  private readonly clientFactory: (baseUrl: string) => OpencodeClient;

  constructor(deps: OpencodeHarnessDeps = {}) {
    this.spawn = deps.spawn ?? defaultSpawn;
    this.clientFactory = deps.clientFactory ?? ((url) => new OpencodeClient(url));
  }

  async start(opts: HarnessStartOpts): Promise<HarnessSession> {
    const server = await this.spawn(opts);
    const client = this.clientFactory(server.baseUrl);
    const { id } = await client.createSession(opts.prompt.slice(0, 60));
    await client.sendPrompt(id, opts.prompt);
    return this.buildSession(client, server, id);
  }

  async resume(id: string): Promise<HarnessSession> {
    throw new Error(`resume(${id}) requires a base url; not used by the runner loop in v1`);
  }

  private buildSession(client: OpencodeClient, server: SpawnedServer, id: string): HarnessSession {
    const controller = new AbortController();
    let idle = false;
    return {
      sendMessage: (text: string) => client.sendPrompt(id, text),
      isIdle: () => idle,
      stop: async () => { controller.abort(); await server.stop(); },
      events: async function* (): AsyncIterable<HarnessEvent> {
        for await (const raw of client.subscribe(controller.signal)) {
          if ((raw as { type?: string }).type === 'session.idle') { idle = true; }
          const normalized = normalizeOpencodeEvent(raw);
          if (normalized) yield normalized;
        }
      },
    };
  }
}
```

```ts
import { createCipheriv, createDecipheriv, randomBytes } from 'node:crypto';

const ALGORITHM = 'aes-256-gcm';

export const createSecretCipher = (key: string) => {
  const keyBuf = Buffer.from(key, 'utf8');
  return {
    encrypt: (plain: string): string => {
      const iv = randomBytes(12);
      const cipher = createCipheriv(ALGORITHM, keyBuf, iv);
      const enc = Buffer.concat([cipher.update(plain, 'utf8'), cipher.final()]);
      return [iv.toString('hex'), cipher.getAuthTag().toString('hex'), enc.toString('hex')].join(':');
    },
    decrypt: (blob: string): string => {
      const [ivHex, tagHex, dataHex] = blob.split(':');
      const decipher = createDecipheriv(ALGORITHM, keyBuf, Buffer.from(ivHex, 'hex'));
      decipher.setAuthTag(Buffer.from(tagHex, 'hex'));
      return Buffer.concat([decipher.update(Buffer.from(dataHex, 'hex')), decipher.final()]).toString('utf8');
    },
  };
};
```

```ts
import { createHmac, timingSafeEqual } from 'node:crypto';

const TTL_MS = 7 * 24 * 60 * 60 * 1000;

export const createSessionCookie = (secret: string) => {
  const sign = (displayName: string): string => {
    const expiry = String(Date.now() + TTL_MS);
    const body = `${Buffer.from(displayName).toString('base64url')}.${expiry}`;
    const mac = createHmac('sha256', secret).update(body).digest('base64url');
    return `${body}.${mac}`;
  };
  const verify = (token: string): string | null => {
    const parts = token.split('.');
    if (parts.length !== 3) return null;
    const [nameB64, expiry, mac] = parts;
    const expected = createHmac('sha256', secret).update(`${nameB64}.${expiry}`).digest('base64url');
    if (mac.length !== expected.length || !timingSafeEqual(Buffer.from(mac), Buffer.from(expected))) return null;
    if (Number(expiry) < Date.now()) return null;
    return Buffer.from(nameB64, 'base64url').toString('utf8');
  };
  return { sign, verify };
};
```

`worker-token.ts`:
```ts
import { createHash, randomBytes, timingSafeEqual } from 'node:crypto';

const hashToken = (token: string): string => createHash('sha256').update(token).digest('hex');

export const mintWorkerToken = (): { token: string; hash: string } => {
  const token = randomBytes(32).toString('hex');
  return { token, hash: hashToken(token) };
};

export const verifyWorkerToken = (token: string, hash: string): boolean => {
  const actual = Buffer.from(hashToken(token));
  const expected = Buffer.from(hash);
  return actual.length === expected.length && timingSafeEqual(actual, expected);
};
```

```ts
import type { StreamEvent } from '@sage/shared';

type Resolver = (e: StreamEvent) => void;

export const createEventBus = () => {
  const waiters = new Map<string, Resolver[]>();
  const queues = new Map<string, StreamEvent[]>();

  const publish = (taskId: string, e: StreamEvent): void => {
    const w = waiters.get(taskId);
    if (w && w.length) { w.shift()!(e); return; }
    const q = queues.get(taskId) ?? [];
    q.push(e);
    queues.set(taskId, q);
  };

  const subscribe = (taskId: string): AsyncIterable<StreamEvent> => ({
    [Symbol.asyncIterator]: () => ({
      next: async (): Promise<IteratorResult<StreamEvent>> => {
        const q = queues.get(taskId);
        if (q && q.length) return { value: q.shift()!, done: false };
        const value = await new Promise<StreamEvent>((resolve) => {
          const list = waiters.get(taskId) ?? [];
          list.push(resolve);
          waiters.set(taskId, list);
        });
        return { value, done: false };
      },
    }),
  });

  return { publish, subscribe };
};
```

```ts
import type { IngestEvent, StreamEvent } from '@sage/shared';
import { desc, eq, gt, and } from 'drizzle-orm';

import type { Db } from '../db/client';
import { events } from '../db/schema';

export const assignSeqs = (maxSeq: number, batch: IngestEvent[], createdAt: string): StreamEvent[] =>
  batch.map((e, i) => ({ seq: maxSeq + 1 + i, type: e.type, payload: e.payload, createdAt }));

export const createEventStore = (db: Db) => ({
  append: async (taskId: string, batch: IngestEvent[]): Promise<StreamEvent[]> => {
    return db.transaction(async (tx) => {
      const [last] = await tx.select({ seq: events.seq }).from(events)
        .where(eq(events.taskId, taskId)).orderBy(desc(events.seq)).limit(1);
      const assigned = assignSeqs(last?.seq ?? 0, batch, new Date().toISOString());
      if (assigned.length) {
        await tx.insert(events).values(assigned.map((e) => ({ taskId, seq: e.seq, type: e.type, payload: e.payload })));
      }
      return assigned;
    });
  },
  readSince: async (taskId: string, afterSeq: number): Promise<StreamEvent[]> => {
    const rows = await db.select().from(events)
      .where(and(eq(events.taskId, taskId), gt(events.seq, afterSeq))).orderBy(events.seq);
    return rows.map((r) => ({ seq: r.seq, type: r.type as StreamEvent['type'], payload: r.payload as Record<string, unknown>, createdAt: r.createdAt.toISOString() }));
  },
});
```

`auth-plugin.ts`:

```ts
import cookie from '@fastify/cookie';
import type { FastifyInstance, FastifyReply, FastifyRequest } from 'fastify';

import { createSessionCookie } from './session-cookie';

const COOKIE_NAME = 'vm_session';

declare module 'fastify' {
  interface FastifyInstance { requireUser: (req: FastifyRequest, reply: FastifyReply) => Promise<void> }
  interface FastifyRequest { displayName?: string }
}

export const registerAuth = (app: FastifyInstance, opts: { appPassword: string; sessionSecret: string }): void => {
  const sc = createSessionCookie(opts.sessionSecret);
  if (!app.hasPlugin?.('@fastify/cookie')) app.register(cookie);

  app.post('/api/login', async (req, reply) => {
    const { displayName, password } = (req.body ?? {}) as { displayName?: string; password?: string };
    if (!displayName || password !== opts.appPassword) return reply.code(401).send({ error: 'invalid credentials' });
    reply.setCookie(COOKIE_NAME, sc.sign(displayName), { httpOnly: true, sameSite: 'lax', path: '/' });
    return { displayName };
  });

  app.decorate('requireUser', async (req: FastifyRequest, reply: FastifyReply) => {
    const token = req.cookies?.[COOKIE_NAME];
    const name = token ? sc.verify(token) : null;
    if (!name) return reply.code(401).send({ error: 'unauthorized' });
    req.displayName = name;
  });
};
```

```ts
import Docker from 'dockerode';

import type { AppConfig } from '../config';
import type { Repo } from '@sage/shared';

export interface SpawnInput {
  taskId: string; repo: Repo; prompt: string; workerToken: string; env: Record<string, string>;
}
type DockerLike = Pick<Docker, 'createContainer' | 'getContainer'>;
type DockerFactory = () => DockerLike;

const toEnvArray = (record: Record<string, string>): string[] =>
  Object.entries(record).map(([k, v]) => `${k}=${v}`);

export const createWorkerSpawner = (config: AppConfig, dockerFactory: DockerFactory = () => new Docker()) => {
  const docker = dockerFactory();
  return {
    spawn: async (input: SpawnInput): Promise<{ containerId: string }> => {
      const env = {
        CONTROL_PLANE_URL: config.controlPlaneUrl,
        TASK_ID: input.taskId,
        WORKER_TOKEN: input.workerToken,
        GIT_URL: input.repo.gitUrl,
        BRANCH: `task/${input.taskId}`,
        DEFAULT_BRANCH: input.repo.defaultBranch,
        PROMPT: input.prompt,
        SETUP_CMDS: JSON.stringify(input.repo.setupCmds),
        VALIDATE_CMDS: JSON.stringify(input.repo.validateCmds),
        ...input.env,
      };
      const container = await docker.createContainer({ Image: config.workerImage, Env: toEnvArray(env), Tty: false });
      await container.start();
      return { containerId: container.id };
    },
    retire: async (containerId: string): Promise<void> => {
      await docker.getContainer(containerId).remove({ force: true }).catch(() => undefined);
    },
  };
};
```

```ts
import { LinearClient as Sdk } from '@linear/sdk';
import { eq } from 'drizzle-orm';

import { createSecretCipher } from '../crypto/secret-cipher';
import type { Db } from '../db/client';
import { secrets } from '../db/schema';

const LINEAR_SECRET_KEY = 'LINEAR_API_KEY';

export const createLinearClient = (db: Db, secretsKey = process.env.SECRETS_KEY ?? '') => {
  const cipher = createSecretCipher(secretsKey || '0'.repeat(32));
  const resolveKey = async (): Promise<string | null> => {
    const [row] = await db.select().from(secrets).where(eq(secrets.key, LINEAR_SECRET_KEY)).limit(1);
    return row ? cipher.decrypt(row.valueEncrypted) : null;
  };
  return {
    fetchTicket: async (ref: string): Promise<{ title: string; description: string } | null> => {
      const key = await resolveKey();
      if (!key) return null;
      const issue = await new Sdk({ apiKey: key }).issue(ref);
      return { title: issue.title, description: issue.description ?? '' };
    },
    mirrorStatus: async (ref: string, _status: string, comment: string): Promise<void> => {
      const key = await resolveKey();
      if (!key) return;
      const sdk = new Sdk({ apiKey: key });
      const issue = await sdk.issue(ref);
      await sdk.createComment({ issueId: issue.id, body: comment });
    },
  };
};
```

`task-service.ts`:
```ts
import { TaskSource, TaskStatus, type CreateTaskInput, type Task } from '@sage/shared';
import { desc, eq } from 'drizzle-orm';

import type { AppConfig } from '../config';
import type { Db } from '../db/client';
import { createSecretCipher } from '../crypto/secret-cipher';
import { mintWorkerToken } from '../auth/worker-token';
import { repos, secrets, tasks } from '../db/schema';
import type { EventStore } from '../events/event-store';
import type { EventBus } from '../events/event-bus';

interface TaskServiceDeps {
  db: Db; eventStore: EventStore; eventBus: EventBus;
  spawner: { spawn: (i: never) => Promise<{ containerId: string }>; retire: (id: string) => Promise<void> };
  linear: { fetchTicket: (ref: string) => Promise<{ title: string; description: string } | null>;
    mirrorStatus: (ref: string, status: string, comment: string) => Promise<void> };
  config: AppConfig;
}

const rowToTask = (r: typeof tasks.$inferSelect): Task => ({
  id: r.id, repoId: r.repoId, source: r.source as TaskSource, linearRef: r.linearRef, prompt: r.prompt,
  status: r.status as TaskStatus, branch: r.branch, prUrl: r.prUrl, createdBy: r.createdBy,
  containerId: r.containerId, createdAt: r.createdAt.toISOString(),
});

export const createTaskService = (deps: TaskServiceDeps) => {
  const cipher = createSecretCipher(deps.config.secretsKey ?? '0'.repeat(32));
  const resolveSecret = async (key: string): Promise<string | undefined> => {
    const [row] = await deps.db.select().from(secrets).where(eq(secrets.key, key)).limit(1);
    return row ? cipher.decrypt(row.valueEncrypted) : undefined;
  };

  const create = async (input: CreateTaskInput, createdBy: string): Promise<Task> => {
    let prompt = input.prompt ?? '';
    if (input.source === TaskSource.LINEAR && input.linearRef) {
      const ticket = await deps.linear.fetchTicket(input.linearRef);
      prompt = ticket ? `${ticket.title}\n\n${ticket.description}` : `Linear ${input.linearRef}`;
    }
    const [repo] = await deps.db.select().from(repos).where(eq(repos.id, input.repoId)).limit(1);
    if (!repo) throw new Error('repo not found');
    const { token, hash } = mintWorkerToken();
    const [row] = await deps.db.insert(tasks).values({
      repoId: input.repoId, source: input.source, linearRef: input.linearRef ?? null, prompt,
      status: TaskStatus.QUEUED, createdBy, branch: null, workerTokenHash: hash,
    }).returning();

    await deps.db.update(tasks).set({ status: TaskStatus.PROVISIONING, branch: `task/${row.id}` }).where(eq(tasks.id, row.id));
    const env: Record<string, string> = {};
    for (const k of ['GITHUB_TOKEN', 'NODE_AUTH_TOKEN']) {
      const v = await resolveSecret(k);
      if (v) env[k] = v;
    }
    const { containerId } = await deps.spawner.spawn({
      taskId: row.id, repo: { ...repo, setupCmds: repo.setupCmds as string[], validateCmds: repo.validateCmds as string[] } as never,
      prompt, workerToken: token, env,
    } as never);
    await deps.db.update(tasks).set({ containerId }).where(eq(tasks.id, row.id));
    return { ...rowToTask(row), status: TaskStatus.PROVISIONING, branch: `task/${row.id}`, containerId };
  };

  return {
    create,
    list: async (createdBy?: string): Promise<Task[]> => {
      const base = deps.db.select().from(tasks).orderBy(desc(tasks.createdAt));
      const rows = createdBy ? await base.where(eq(tasks.createdBy, createdBy)) : await base;
      return rows.map(rowToTask);
    },
    get: async (id: string): Promise<Task | null> => {
      const [row] = await deps.db.select().from(tasks).where(eq(tasks.id, id)).limit(1);
      return row ? rowToTask(row) : null;
    },
    cancel: async (id: string): Promise<void> => {
      const [row] = await deps.db.select().from(tasks).where(eq(tasks.id, id)).limit(1);
      if (row?.containerId) await deps.spawner.retire(row.containerId);
      await deps.db.update(tasks).set({ status: TaskStatus.CANCELLED }).where(eq(tasks.id, id));
    },
  };
};
export type TaskService = ReturnType<typeof createTaskService>;
```

```ts
import { EventType, TaskStatus, ingestEventSchema } from '@sage/shared';
import { and, eq, isNull, z } from 'drizzle-orm';
import type { FastifyInstance, FastifyReply, FastifyRequest } from 'fastify';

import type { AppDeps } from '../app';
import { verifyWorkerToken } from '../auth/worker-token';
import { inboundMessages, tasks } from '../db/schema';

const TERMINAL = new Set([TaskStatus.DONE, TaskStatus.FAILED, TaskStatus.NEEDS_ASSISTANCE]);

const guardWorker = (deps: AppDeps) => async (req: FastifyRequest, reply: FastifyReply) => {
  const token = req.headers['x-worker-token'];
  const { id } = req.params as { id: string };
  const [task] = await deps.db.select().from(tasks).where(eq(tasks.id, id)).limit(1);
  if (!task?.workerTokenHash || typeof token !== 'string' || !verifyWorkerToken(token, task.workerTokenHash)) {
    return reply.code(401).send({ error: 'bad worker token' });
  }
};

export const registerInternalRoutes = (app: FastifyInstance, deps: AppDeps): void => {
  const guard = guardWorker(deps);
  app.post('/internal/tasks/:id/events', { preHandler: guard }, async (req) => {
    const { id } = req.params as { id: string };
    const batch = z.array(ingestEventSchema).parse(req.body);
    const stored = await deps.eventStore.append(id, batch);
    for (const e of stored) {
      deps.eventBus.publish(id, e);
      if (e.type === EventType.STATUS && typeof e.payload.status === 'string') {
        const status = e.payload.status as TaskStatus;
        await deps.db.update(tasks).set({ status }).where(eq(tasks.id, id));
        if (TERMINAL.has(status)) {
          const [task] = await deps.db.select().from(tasks).where(eq(tasks.id, id)).limit(1);
          if (task?.linearRef) await deps.taskService /* see note */ ;
        }
      }
      if (e.type === EventType.PR_OPENED && typeof e.payload.url === 'string') {
        await deps.db.update(tasks).set({ prUrl: e.payload.url as string }).where(eq(tasks.id, id));
      }
    }
    return { accepted: stored.length };
  });

  app.get('/internal/tasks/:id/messages', { preHandler: guard }, async (req) => {
    const { id } = req.params as { id: string };
    const pending = await deps.db.select().from(inboundMessages)
```

```ts
import type { StreamEvent } from '@sage/shared';
import type { FastifyInstance } from 'fastify';

import type { AppDeps } from '../app';

export const formatSseFrame = (e: StreamEvent): string =>
  `id: ${e.seq}\nevent: ${e.type}\ndata: ${JSON.stringify(e.payload)}\n\n`;

export const registerStreamRoute = (app: FastifyInstance, deps: AppDeps): void => {
  app.get('/api/tasks/:id/stream', { preHandler: app.requireUser }, async (req, reply) => {
    const { id } = req.params as { id: string };
    const lastEventId = Number(req.headers['last-event-id'] ?? (req.query as { lastEventId?: string }).lastEventId ?? 0);

    reply.raw.writeHead(200, {
      'content-type': 'text/event-stream',
      'cache-control': 'no-cache',
      connection: 'keep-alive',
    });

    const replay = await deps.eventStore.readSince(id, Number.isFinite(lastEventId) ? lastEventId : 0);
    for (const e of replay) reply.raw.write(formatSseFrame(e));

    let open = true;
    req.raw.on('close', () => { open = false; });
    for await (const e of deps.eventBus.subscribe(id)) {
      if (!open) break;
      reply.raw.write(formatSseFrame(e));
    }
  });
};
```

`worker/src/runner.ts`:
```ts
import { EventType, TaskStatus, type IngestEvent } from '@sage/shared';
import type { Harness, HarnessStartOpts } from '@sage/harness';

export interface RunLoopDeps {
  harness: Harness;
  startOpts: HarnessStartOpts;
  validate: () => Promise<{ ok: boolean; output: string }>;
  drainMessages: () => Promise<string[]>;
  emit: (e: IngestEvent) => Promise<void>;
  maxIterations?: number;
}

const drainUntilIdle = async (
  session: Awaited<ReturnType<Harness['start']>>,
  emit: (e: IngestEvent) => Promise<void>,
): Promise<void> => {
  for await (const event of session.events()) {
    await emit({ type: event.type, payload: event.payload });
    if (session.isIdle()) break;
  }
};

export const runLoop = async (deps: RunLoopDeps): Promise<TaskStatus> => {
  const max = deps.maxIterations ?? 3;
  const session = await deps.harness.start(deps.startOpts);
  await emitStatus(deps.emit, TaskStatus.RUNNING);

  for (let i = 0; i < max; i += 1) {
    await drainUntilIdle(session, deps.emit);
    for (const msg of await deps.drainMessages()) {
      await deps.emit({ type: EventType.USER_MESSAGE, payload: { text: msg } });
      await session.sendMessage(msg);
      await drainUntilIdle(session, deps.emit);
    }
    const result = await deps.validate();
    if (result.ok) { await session.stop(); return TaskStatus.DONE; }
    await deps.emit({ type: EventType.LOG, payload: { line: `validation failed (attempt ${i + 1})` } });
    if (i < max - 1) await session.sendMessage(`Validation failed:\n${result.output}\nPlease fix and continue.`);
  }
  await session.stop();
  return TaskStatus.NEEDS_ASSISTANCE;
};

const emitStatus = (emit: (e: IngestEvent) => Promise<void>, status: TaskStatus): Promise<void> =>
  emit({ type: EventType.STATUS, payload: { status } });
```

```ts
import { join } from 'node:path';

import { EventType, TaskStatus } from '@sage/shared';
import { OpencodeHarness } from '@sage/harness';
import { execa } from 'execa';

import { createControlPlaneClient } from './control-plane-client';
import { cloneAndCheckout, pushBranch } from './git-ops';
import { openPr } from './gh-ops';
import { runLoop } from './runner';
import { writeSoul } from './soul';

const env = (k: string): string => process.env[k] ?? '';

const runValidate = (dir: string, cmds: string[]) => async (): Promise<{ ok: boolean; output: string }> => {
  for (const cmd of cmds) {
    const result = await execa(cmd, { cwd: dir, shell: true, reject: false });
    if (result.exitCode !== 0) return { ok: false, output: result.stdout + result.stderr };
  }
  return { ok: true, output: '' };
};

const main = async (): Promise<void> => {
  const dir = await mkdtemp(join(tmpdir(), 'vm-'));
  const branch = env('BRANCH');
  const client = createControlPlaneClient(env('CONTROL_PLANE_URL'), env('TASK_ID'), env('WORKER_TOKEN'));
  const emit = (e: { type: EventType; payload: Record<string, unknown> }) => client.emit([e]);

  await cloneAndCheckout(env('GIT_URL'), dir, branch);
  const soulPath = await writeSoul(dir);
  const validateCmds = JSON.parse(env('VALIDATE_CMDS') || '[]') as string[];

  const status = await runLoop({
    harness: new OpencodeHarness(),
    startOpts: { cwd: dir, prompt: env('PROMPT'), systemPromptPath: soulPath },
    validate: runValidate(dir, validateCmds),
    drainMessages: client.drainMessages,
    emit,
  });

  if (status === TaskStatus.DONE) {
    await emit({ type: EventType.STATUS, payload: { status: TaskStatus.PUSHING } });
    await pushBranch(dir, branch);
    const prUrl = await openPr(dir, `Sage: ${env('TASK_ID')}`, env('DEFAULT_BRANCH'));
    if (prUrl) await emit({ type: EventType.PR_OPENED, payload: { url: prUrl } });
    await emit({ type: EventType.STATUS, payload: { status: TaskStatus.DONE } });
  } else {
    await emit({ type: EventType.STATUS, payload: { status } });
  }
};

main().catch(async (err) => {
  const client = createControlPlaneClient(env('CONTROL_PLANE_URL'), env('TASK_ID'), env('WORKER_TOKEN'));
  await client.emit([{ type: EventType.ERROR, payload: { message: String(err) } }]);
  await client.emit([{ type: EventType.STATUS, payload: { status: TaskStatus.FAILED } }]);
  process.exit(1);
});
```

```ts
export class ApiError extends Error {
  constructor(public status: number, message: string) { super(message); }
}

export const createApiClient = (baseUrl: string) => {
  const request = async <T>(method: string, path: string, body?: unknown): Promise<T> => {
    const res = await fetch(`${baseUrl}${path}`, {
      method,
      credentials: 'include',
      headers: body ? { 'content-type': 'application/json' } : undefined,
      body: body ? JSON.stringify(body) : undefined,
    });
    if (!res.ok) throw new ApiError(res.status, await res.text());
    return res.status === 204 ? (undefined as T) : ((await res.json()) as T);
  };
  return {
    get: <T>(path: string) => request<T>('GET', path),
    post: <T>(path: string, body?: unknown) => request<T>('POST', path, body),
    put: <T>(path: string, body?: unknown) => request<T>('PUT', path, body),
    del: <T>(path: string) => request<T>('DELETE', path),
  };
};

export const apiClient = createApiClient('');
```

```ts
import { type CreateTaskInput, type Repo, type Task } from '@sage/shared';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';

import { apiClient } from './client';

export const useTasks = (mine: boolean) =>
  useQuery({ queryKey: ['tasks', mine], queryFn: () => apiClient.get<Task[]>(`/api/tasks${mine ? '?mine=1' : ''}`), refetchInterval: 5000 });

export const useTask = (id: string) =>
  useQuery({ queryKey: ['task', id], queryFn: () => apiClient.get<Task>(`/api/tasks/${id}`) });

export const useRepos = () =>
  useQuery({ queryKey: ['repos'], queryFn: () => apiClient.get<Repo[]>('/api/repos') });

export const useCreateTask = () => {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (input: CreateTaskInput) => apiClient.post<Task>('/api/tasks', input),
    onSuccess: () => qc.invalidateQueries({ queryKey: ['tasks'] }),
  });
};

export const useCancelTask = () => {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (id: string) => apiClient.post(`/api/tasks/${id}/cancel`),
    onSuccess: () => qc.invalidateQueries({ queryKey: ['tasks'] }),
  });
};

export const useSendMessage = (id: string) =>
  useMutation({ mutationFn: (body: string) => apiClient.post(`/api/tasks/${id}/messages`, { body }) });
```

`src/tasks/useTaskStream.ts`:
```ts
import { type EventType, type StreamEvent } from '@sage/shared';
import { useEffect, useRef, useState } from 'react';

const TYPES: EventType[] = ['log', 'tool', 'assistant', 'user_message', 'status', 'error', 'pr_opened'] as never;

export const useTaskStream = (taskId: string): { events: StreamEvent[]; connected: boolean } => {
  const [events, setEvents] = useState<StreamEvent[]>([]);
  const [connected, setConnected] = useState(false);
  const seen = useRef<Set<number>>(new Set());

  useEffect(() => {
    const es = new EventSource(`/api/tasks/${taskId}/stream`, { withCredentials: true });
    es.onopen = () => setConnected(true);
    es.onerror = () => setConnected(false);
    const onEvent = (type: string) => (e: MessageEvent) => {
      const seq = Number(e.lastEventId);
      if (seen.current.has(seq)) return;
      seen.current.add(seq);
      setEvents((prev) => [...prev, { seq, type: type as EventType, payload: JSON.parse(e.data), createdAt: '' }]
        .sort((a, b) => a.seq - b.seq));
    };
    for (const t of TYPES) es.addEventListener(t, onEvent(t));
    return () => es.close();
  }, [taskId]);

  return { events, connected };
};
```
> Replace the `TYPES` cast with the real `EventType` enum values imported from shared (`Object.values(EventType)`); the literal array above is illustrative. Use: `const TYPES = Object.values(EventType);`.
